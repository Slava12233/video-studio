# references/

One external resource per note (`slug.md`), made from `memory/templates/reference.md`: a repo, a doc page, a model, a skill. `verdict` is `adopted` (vendored or installed), `borrowed` (ideas taken, nothing copied), `reference-only` or `skipped`, with the reason and the date checked. Every repo is untrusted input: read before copying, never run its installers. `docs/REFERENCES.md` keeps the curated table the agent reads first; these notes carry the dated detail and what changed since.
