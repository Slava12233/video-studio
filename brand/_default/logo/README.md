# Logo files

Put the brand logo here:

- `logo.svg`: vector, preferred for video (crisp at any size)
- `logo.png`: transparent background, at least 1000 px wide
- `logo-white.svg` / `logo-white.png`: white version for dark stages (optional)

`tools/new-video.mjs` copies every `.svg` / `.png` in this folder into each new project's `assets/`, so compositions
use `assets/logo.svg`. Usage rules are in `../BRAND.md` (clear space, pill on photos).
